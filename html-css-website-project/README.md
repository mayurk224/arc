# University Website Project

A static HTML and CSS website showcasing a modern university landing page with multiple information sections and navigation.

## Overview

This project is a responsive, multi-page website built using pure HTML and CSS. It includes a home page and supporting pages for about, courses, faculties, services, and contact information.

## Features

- Clean university-themed landing page design
- Responsive navigation bar with page links
- Multiple dedicated pages:
  - `index.html` – Home
  - `about.html` – About the university
  - `courses.html` – Offered courses
  - `faculties.html` – Faculty and staff overview
  - `services.html` – Campus services
  - `contact.html` – Contact information
- Consistent styling across pages using CSS files
- SVG logo and decorative imagery
- Modern button styles, cards, and info sections

## Technologies Used

- HTML5
- CSS3

## How to View

1. Open the project folder in your browser or editor.
2. Open `index.html` in a browser to view the homepage.
3. Use the navigation links to explore the other pages.
